# ระบบติดตามงบประมาณ

เว็บแอป Vue 3 สำหรับอ่านงบประมาณจากไฟล์ Excel และบันทึกค่าใช้จ่ายแต่ละรายการ โดยรองรับภาษาไทยและใช้งานแบบ PWA

## คุณสมบัติ

- ให้ผู้ใช้เลือกไฟล์ `.xlsx` จากเครื่องก่อนเริ่มใช้งาน ไม่มีไฟล์เริ่มต้นที่โหลดอัตโนมัติ
- ตรวจจับชีตและตารางจากหัวคอลัมน์ `รายการ`, `รายละเอียด`, `จำนวน (บาท)` และ `รวม`
- ตรวจจับคอลัมน์งวดระหว่าง `จำนวน (บาท)` กับ `รวม`
- แสดงรายละเอียดตาราง งบตามงวด และยอดสรุป
- บันทึกจำนวนเงินพร้อมรายละเอียดหลายบรรทัดในหนึ่งธุรกรรม
- หักยอดใช้จ่ายออกจากงบรายการและแสดงยอดคงเหลือ
- เก็บประวัติธุรกรรมใน `localStorage` ของเบราว์เซอร์

## โครงสร้าง Excel

ตัวเลขจำนวนเต็มในคอลัมน์ก่อน `รายการ` ใช้เป็นจุดเริ่มตาราง เช่น `1`, `2`, `3`

แถวท้ายสุดก่อนตารางถัดไปใช้เป็นแถวสรุป ตารางที่มีหมายเลข `3.1` จะถือเป็นหัวข้อย่อย ถ้ามีรายละเอียดและจำนวนเงินก็จะแสดงเป็นรายการใช้จ่ายได้

> ระบบใช้ค่าที่ Excel บันทึกไว้ล่าสุด หากสูตรยังไม่ถูกคำนวณ ควรเปิดและบันทึกไฟล์ด้วย Excel ก่อนนำเข้า

## การพัฒนา

```bash
npm install
npm run dev
```

สร้างสำหรับ production:

```bash
npm run build
```

ข้อมูลใช้จ่ายจัดเก็บเฉพาะในเครื่อง ไม่ได้แก้ไขไฟล์ Excel ต้นฉบับ
